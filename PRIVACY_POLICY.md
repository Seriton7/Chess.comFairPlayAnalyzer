# Privacy Policy

**Last updated:** October 3, 2026

Chess.com Fair Play Analyzer "The Extension" is a browser extension that analyzes publicly available Chess.com player and game data and provides statistical fair-play indicators.

## 1. Data Accessed by the Extension

The Extension accesses publicly available information from the Chess.com API when a user enters a Chess.com username for analysis.

Depending on the information publicly available for the selected player, the Extension may access:

- Chess.com username
- Country
- Public profile avatar
- Public account status and title
- Account creation date
- Last online timestamp
- Number of followers
- Public ratings for Rapid, Blitz, and Bullet
- Public game records, including wins, losses, and draws
- Public rating history
- Public game accuracy information
- Public game metadata required to calculate statistical indicators

The Extension only uses this information to perform the requested player analysis and display the results to the user.

## 2. User Personal Data

The Extension does not require users to create an account or provide personal information.

The Extension does not intentionally collect or store the user's:

- Name
- Email address
- Passwords or authentication credentials
- Payment information
- Private messages
- Precise location
- Browsing history
- Keystrokes or mouse activity

The username entered by the user is used only to request the corresponding publicly available Chess.com data.

## 3. Data Storage

The Extension does not operate its own server or database for storing Chess.com player data.

Data retrieved from the Chess.com API is processed locally by the Extension to calculate statistics and display the analysis.

The Extension does not intentionally retain the analyzed player data after the analysis is completed.

## 4. Data Sharing

The Extension does not sell, rent, or share user data with third parties.

To provide its functionality, the Extension makes requests to publicly available Chess.com API endpoints and retrieves publicly available Chess.com resources, such as player avatars.

No player data is sent to a server operated by the developer of the Extension.

## 5. Fair Play Score

The Extension calculates a statistical "Fair Play Score" using publicly available player and game information.

The Fair Play Score is an analytical indicator created by the Extension. It is **not an official Chess.com determination of cheating or fair play**.

A low score does not prove that a player is cheating, and a high score does not prove that a player is definitely playing fairly.

The accuracy of the analysis depends on the amount, availability, and quality of the publicly accessible Chess.com data.

## 6. Third-Party Services

The Extension uses publicly available resources provided by Chess.com, including:

* Chess.com public API
* Chess.com-hosted player images

The availability and use of these resources are subject to Chess.com's own terms and policies.

## 7. Changes to This Privacy Policy

This Privacy Policy may be updated if the Extension's functionality or data practices change.

Any updated version will be published at the same location as this Privacy Policy.
